      SECURITY GUIDE

      Password Security Tips

      Follow these practices to create passwords that are harder to guess and safer to use across your accounts.

      01

      Use Long Passwords

      Prefer long passwords or passphrases. Length generally provides stronger resistance against brute-force guessing.

      02

      Use a Unique Password

      Never reuse the same password across important accounts. A breach of one service should not expose your other accounts.

      03

      Avoid Predictable Patterns

      Avoid sequences such as 123456, qwerty, repeated characters, common words and simple substitutions.

      04

      Avoid Personal Information

      Don't use names, birthdays, phone numbers or other information that could be discovered about you.

      05

      Consider a Password Manager

      A password manager can generate and store unique passwords so you don't need to memorize every password.

      06

      Enable Multi-Factor Authentication

      MFA provides an additional layer of protection if a password is compromised.
